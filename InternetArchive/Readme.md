
1. Introduction 

The 'Les jetés de L'Encre' booklet are stored in Internet Archive on the site
https://archive.org 
The account  logine is the email address gilles@lesjetesdelencre.com
The passwd is not given here 


On archive.org the lesjetesdelencre.com site gives 5 files : 

- LJDE_Text.pdf : for the Text only PDF without any chord  in A4 format
- LJDE_Text2.pdf : for the Text only PDF without any chord but for booklets
with 2 A5 format to be cut 
- LJDE_LyricsName.pdf : for the Text with the name of chord inside the PDF in
A4 format
- LJDE_LyricsChord.pdf : for the Text with the grid of the chord inside the PDF
in A4 format
- LJDE_Chord.pdf : for the chord only of each songs

The Lesjetesdelencre.com site reference this five booklets. 

On each booklet release (for each new song) you have to upload this files from
ChordV program (available in sourceforge.net)



2. Checking

- When LJDE_Text.pdf, LJDE_Text2.pdf, LJDE_lyricsName.pdf, LJDE_lyricsChord.pdf
and LJDE_Chord.pdf are uploaded exactly with these names
